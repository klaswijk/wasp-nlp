# AI Usage

Assignments 1 and 2 were coded in Visual Studio Code with Copilot enabled for code completion. Agentic AI was used to add command line arguments, mixed-precision training, and plotting.

Assignments 3 and 4 were coded in Google Colab. Gemini was used to fix errors and generate some boiler-plate code, like plotting the confusion matrix and repots with scikit-learn. The code completion was also enabled.
